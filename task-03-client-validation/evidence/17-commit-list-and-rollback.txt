5. WHY NAMING THE COMMIT ID IS SAFER THAN NATURAL LANGUAGE
--------------------------------------------------------------------------------
Naming an exact 40-character SHA hash (or unique 7-character short hash) is cryptographically deterministic: Git points to an immutable Merkle tree snapshot containing the exact byte-for-byte state of every file. In contrast, describing a rollback in natural language ("undo the last two versions" or "remove the changes to the labels") forces an AI agent or developer to guess what changed, which frequently introduces silent regressions, partial restorations, and hallucinated code deletions.
