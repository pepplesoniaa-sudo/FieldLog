# FieldLog

FieldLog lets field supervisors on environmental sites capture photos and notes once, even offline, and turns them into a daily report a reviewer approves. The one thing that must work: no captured entry is ever lost.

This is one repository. The app lives at the root; each task-0N folder holds that task's docs and evidence.
